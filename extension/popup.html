MCP 安装（npm · 需 Node ≥ 18）
Claude Code
claude mcp add browser-link-tool -s user -- npx -y browser-link-tool
Codex
codex mcp add browser-link-tool -- npx -y browser-link-tool
JoyCode · 追加到 ~/.joycode/config.toml
[mcp_servers.browser-link-tool] command = "npx" args = ["-y", "browser-link-tool"]

"browser-link-tool": { "command": "npx", "args": ["-y", "browser-link-tool"] }
